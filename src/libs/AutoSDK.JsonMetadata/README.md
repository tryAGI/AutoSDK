# AutoSDK.JsonMetadata

A build-only analyzer for shared JSON metadata. AutoSDK emits a metadata manifest alongside the SDK source. The analyzer runs the pinned official System.Text.Json generator against the complete SDK compilation, then emits static metadata factories. Generated narrow resolvers reference the factories they need, so the linker can remove unrelated factories and models.

Use the package with `PrivateAssets="all"`. The SDK's published runtime dependencies do not include this analyzer or Roslyn. The generator CLI has no dependency on this component and retains its NativeAOT path.

## Compatibility

The component pins the official System.Text.Json source generator to 10.0.13 and accepts metadata generation only. It preserves the official property, constructor, converter, required-member and callback metadata. Unsupported instance-dependent output, missing metadata or generator errors produce AMETA001 rather than a reflection fallback.

Ordinary JsonSerializerContext implementations in the same SDK, such as a separate Realtime namespace, are generated by the normal compiler generator and remain outside this component's transformation.

## Dependency provenance

- System.Text.Json 10.0.13: Microsoft/.NET, MIT, compiler generator binary only.
- Microsoft.CodeAnalysis.CSharp 4.8.0 and its dependencies: Microsoft/.NET, MIT, compiler/test infrastructure.
- AutoSDK.JsonMetadata: first-party build infrastructure. No analyzer dependency is copied into a generated SDK's runtime package.

The metadata manifest extension is `.autosdk-json-metadata`. The package's build props register those files as AdditionalFiles. Metadata factory shapes are checked in tests; compiler-version changes require focused compatibility and trimmed/NativeAOT runtime validation.
